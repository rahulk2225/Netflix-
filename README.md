# Netflix Data Analysis Using Power BI

This project focuses on analyzing Netflix content and customer viewing behavior using Power BI.

## Project Overview

The dashboard provides insights into:

- Customer engagement and demographics
- Top 10 most-watched movies and TV shows
- Content ratings and genre performance
- Subscription type and watch time
- Age-group analysis
- Country-wise Netflix content distribution
- Director and cast rating analysis
- Release-year and content trends

## Key Dashboard KPIs

- Total Titles Watched: 19.049K
- Average Rating: 3.01
- Total Watch Time: 50M
- Total Customers: 20K

## Tools & Technologies

- Power BI
- Excel
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis (EDA)
- Business Intelligence
